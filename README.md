# Retail Profitability & Risk Analysis

## Overview

This project analyzes retail sales data to identify profitability trends and predict high-risk orders using machine learning. The solution combines data analysis, visualization, and predictive modeling to support business decision-making.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Power BI
- Streamlit

## Features

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Profitability Trend Analysis
- Machine Learning Risk Prediction
- Power BI Dashboard
- Streamlit Application (ProfitGuard)

## Project Structure

- `APP.py` - Streamlit application
- `utils.py` - Helper functions
- `Retail_Profitability_Analysis.ipynb` - Data analysis notebook
- `model.pkl` - Trained machine learning model
- `Sample-Superstore_cleaned.csv` - Dataset

## Key Insights

- Higher discounts negatively affect profitability.
- Profitability varies across regions and product categories.
- Machine learning can identify high-risk orders before business losses occur.
